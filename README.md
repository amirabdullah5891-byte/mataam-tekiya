## النشر على Vercel

1. ارفع المشروع إلى GitHub
2. اربطه بـ Vercel
3. أضف متغير البيئة `DATABASE_URL` برابط PostgreSQL
4. انشر!

## التقنيات

- Next.js 16 + TypeScript
- Prisma ORM + PostgreSQL
- Tailwind CSS 4 + shadcn/ui
- Recharts للرسوم البيانية
- خط Cairo العربي
