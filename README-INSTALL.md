# 🍽️ مطعم التكية - نظام الحسابات

## التثبيت السريع (3 خطوات)

### الخطوة 1: تثبيت Bun
- **ويندوز** (PowerShell كمسؤول):
  ```powershell
  irm bun.sh/install.ps1 | iex
  ```
- **لينكس/ماك**:
  ```bash
  curl -fsSL https://bun.sh/install | bash
  ```

### الخطوة 2: فك الضغط وتثبيت المكتبات
1. فك ضغط ملف ZIP في مجلد (مثل `C:\restaurant`)
2. افتح الطرفية (Terminal/PowerShell) في المجلد
3. شغّل:
   ```bash
   bun install
   bun run db:push
   ```

### الخطوة 3: تشغيل النظام
```bash
bun run start:all
```

**هذا كل شيء!** سيفتح النظام على http://localhost:3000

## بيانات الدخول الافتراضية
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

---

## الأوامر المفيدة
| الأمر | الوصف |
|---|---|
| `bun run start:all` | تشغيل النظام |
| `bun run stop` | إيقاف النظام |
| `bun run install:shortcut` | إنشاء اختصار على سطح المكتب |
| `bun run backup` | نسخة احتياطية |
| `bun run restore` | استرجاع نسخة |

---

## الوصول من الهاتف
1. شغّل النظام على الكمبيوتر
2. تأكد أن الهاتف على نفس شبكة WiFi
3. على الهاتف، افتح: `http://IP_OF_COMPUTER:3000/menu`
4. أو امسح QR Code من: `http://localhost:3000/qrcode`
