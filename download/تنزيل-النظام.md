## خطوات التثبيت بعد التنزيل

### الخطوة 1: تثبيت Bun (محرك التشغيل)

**ويندوز** (PowerShell كمسؤول):
```powershell
irm bun.sh/install.ps1 | iex
```

**لينكس/ماك**:
```bash
curl -fsSL https://bun.sh/install | bash
```

### الخطوة 2: فك الضغط

**ويندوز:**
- فك ضغط `mataam-tekiya-system.zip` في مجلد (مثل `C:\restaurant`)

**لينكس/ماك:**
```bash
tar xzf mataam-tekiya-system.tar.gz
cd my-project
```

### الخطوة 3: تثبيت المكتبات

افتح الطرفية في مجلد المشروع وشغّل:
```bash
bun install
bun run db:push
```

### الخطوة 4: تشغيل النظام

```bash
bun run start:all
```

**هذا كل شيء!** سيفتح النظام على `http://localhost:3000`

## ماذا يحتوي الملف؟

✅ كود المصدر الكامل (Next.js 16 + TypeScript + Prisma)
✅ قاعدة البيانات (تُنشأ تلقائياً عند أول تشغيل)
✅ السكريبتات (نسخ احتياطي، تشغيل، إيقاف)
✅ الأيقونات وملفات PWA
✅ الأدلة الكاملة:
- دليل التشغيل السريع
- دليل التثبيت كتطبيق
- دليل النشر للإنتاج
- دليل QR Code

## ماذا لا يحتوي الملف؟

❌ `node_modules` (تُثبت بـ `bun install`)
❌ قاعدة البيانات الفعلية (تُنشأ بـ `bun run db:push`)
❌ النسخ الاحتياطية (تنشئها أنت بـ `bun run backup`)

## الوصول من الهاتف

بعد تشغيل النظام:
1. تأكد أن الهاتف على نفس شبكة WiFi
2. اطبع QR Code من `http://localhost:3000/qrcode`
