# 🚀 دليل التشغيل السريع - مطعم التكية

## الطريقة الأسهل: تشغيل بنقرة واحدة

### على ويندوز:
1. حمّل المشروع كاملاً إلى مجلد على جهازك (مثل `C:\restaurant`)
2. افتح **PowerShell** أو **Command Prompt**
3. انتقل للمجلد:
   ```cmd
   cd C:\restaurant
   ```
4. شغّل الأمر:
   ```cmd
   bun run start:all
   ```

### على لينكس/ماك:
```bash
cd /path/to/restaurant
bun run start:all
```

**هذا كل شيء!** النظام سيبدأ ويعرض لك عناوين الوصول.

---

## 📋 المتطلبات المسبقة (مرة واحدة فقط)

### 1. تثبيت Bun (محرك التشغيل)

**ويندوز (PowerShell كمسؤول):**
```powershell
irm bun.sh/install.ps1 | iex
```

**لينكس/ماك:**
```bash
curl -fsSL https://bun.sh/install | bash
```

### 2. تثبيت Git (لنسخ المشروع)

حمّله من: https://git-scm.com/downloads

## 🖥️ التشغيل اليومي

بعد التثبيت الأول، كل ما عليك فعله يومياً:

1. **شغّل الكمبيوتر**
2. افتح الطرفية (Terminal/PowerShell)
3. اكتب:
   ```bash
   cd /path/to/restaurant
   bun run start:all
   ```

سيعرض النظام:
```
✅ النظام جاهز للعمل!

📍 عناوين الوصول:
   • على هذا الجهاز:    http://localhost:3000
   • من هاتف على WiFi: http://192.168.1.X:3000
   • المنيو العام:      http://192.168.1.X:3000/menu
   • صفحة QR:           http://192.168.1.X:3000/qrcode

🔐 بيانات الدخول:
   اسم المستخدم: admin
   كلمة المرور:   admin123
```

---

## 📱 الوصول من الهاتف

### الخطوات:
1. تأكد أن **الهاتف والكمبيوتر على نفس شبكة WiFi**
2. على الكمبيوتر، شغّل النظام (`bun run start:all`)
3. لاحظ عنوان IP المعروض (مثل `192.168.1.5`)
4. على هاتف الزبون، افتح المتصفح واكتب:
   ```
   http://192.168.1.5:3000/menu
   ```

### لإنشاء QR Code للطاولات:
1. افتح `http://localhost:3000/qrcode` على الكمبيوتر
2. اطبع البطاقة
3. الزبون يمسحها بكاميرا هاتفه → تفتح القائمة مباشرة

## 🔄 التشغيل التلقائي عند بدء تشغيل الكمبيوتر

### على ويندوز:
1. اضغط `Win + R` واكتب `shell:startup`
2. أنشئ اختصار (Shortcut) لملف `start-windows.bat`
3. ضع الاختصار في المجلد الذي فتح

### على لينكس:
```bash
crontab -e
# أضف السطر التالي:
@reboot cd /path/to/restaurant && bun run start:all
```

## ⏹️ إيقاف النظام

- في الطرفية: اضغط `Ctrl + C`
- أو شغّل: `bun run stop`

---

## 🔧 حل المشاكل الشائعة

### المشكلة: "Bun not found"
**الحل:** ثبّت Bun أولاً (راجع المتطلبات المسبقة)

### المشكلة: "Port 3000 is already in use"
**الحل:** النظام سيحاول إيقاف العملية السابقة تلقائياً. إذا استمرت:
```bash
bun run stop
bun run start:all
```

### المشكلة: الهاتف لا يفتح الموقع
**الحل:**
1. تأكد أن الهاتف على نفس شبكة WiFi
2. تأكد أن عنوان IP صحيح (اكتب `ipconfig` على ويندوز أو `ifconfig` على لينكس)
3. تأكد أن جدار الحماية (Firewall) يسمح بالاتصال على المنفذ 3000

### المشكلة: الفواتير لا تظهر
**الحل:** تأكد أن قاعدة البيانات موجودة:
```bash
bun run db:push
```

## 📞 الدعم السريع

إذا واجهت مشكلة:
1. تحقق من رسائل الخطأ في الطرفية
2. راجع سجل الأحداث في تبويب "سجل الأحداث"
3. استرجع نسخة احتياطية: `bun run restore`
