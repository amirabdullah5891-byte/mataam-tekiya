## ⚠️ خطوات التحديث (مهمة جداً)

### الخطوة 1: إيقاف النظام القديم

**ويندوز:**
- اضغط `Ctrl + C` في نافذة الطرفية التي يشغل فيها النظام
- أو شغّل: `bun run stop`

**لينكس/ماك:**
```bash
cd /path/to/old/restaurant
bun run stop
# أو
pkill -f "next dev"
```

### الخطوة 2: نسخ احتياطي للبيانات الحالية

قبل التحديث، **انسخ قاعدة البيانات** للوضوح:
```bash
cd /path/to/old/restaurant
bun run backup
```

أو انسخ ملف `db/custom.db` يدوياً لمكان آمن.

### الخطوة 3: حذف الملفات القديمة (احتفظ بالبيانات!)

```bash
# في مجلد المشروع القديم
# احتفظ بهذه الملفات:
# - db/custom.db (قاعدة البيانات)
# - public/uploads/ (الصور المرفوعة)
# - .env (إذا عدّلته)

# احذف باقي الملفات القديمة
rm -rf src/ prisma/ scripts/ public/manifest.json public/icon-*.png
rm -f package.json tsconfig.json next.config.ts tailwind.config.ts
```

### الخطوة 4: تنزيل الملف الجديد

حمّل: **[mataam-tekiya-system-v2.zip](mataam-tekiya-system-v2.zip)**

### الخطوة 5: فك الضغط فوق المجلد القديم

فك ضغط `mataam-tekiya-system-v2.zip` في نفس المجلد القديم (استبدل الملفات).

سيُنشئ مجلد `my-project` بداخل الملفات الجديدة.

### الخطوة 6: نقل الملفات للمجلد القديم

```bash
# انقل محتويات my-project إلى مجلد المطعم
cd /path/to/restaurant
cp -r /path/to/extracted/my-project/* .
cp -r /path/to/extracted/my-project/.env.example .
cp -r /path/to/extracted/my-project/.gitignore .
```

### الخطوة 7: تثبيت المكتبات الجديدة

```bash
cd /path/to/restaurant
bun install
```

### الخطوة 8: تحديث قاعدة البيانات

```bash
# تحديث الـ schema (إضافة جداول جديدة)
bun run db:push
```

### الخطوة 9: تشغيل النظام

```bash
bun run start:all
```

## 🔧 حل المشاكل

### المشكلة: "Bun not found"
```bash
# ويندوز
irm bun.sh/install.ps1 | iex

# لينكس/ماك
curl -fsSL https://bun.sh/install | bash
```

### المشكلة: قاعدة البيانات لا تفتح
- تأكد أن `db/custom.db` موجود
- شغّل: `bun run db:push`

### المشكلة: الصور لا تظهر
- تأكد أن مجلد `public/uploads/` موجود وبه الصور

### المشكلة: النظام لا يعمل على المنفذ 3000
- شغّل: `bun run stop`
- ثم: `bun run start:all`
