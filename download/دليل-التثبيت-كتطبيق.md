# 📱 دليل التثبيت كتطبيق - مطعم التكية

## الطريقة 1: تثبيت PWA (الأسهل - على المتصفح)

### على Chrome / Edge (ويندوز):
1. افتح النظام على `http://localhost:3000`
2. في شريط العنوان، اضغط أيقونة **التثبيت** (⊕ على يمين العنوان)
3. أو من قائمة المتصفح (⋮) → **تثبيت التطبيق / Install app**
4. ستظهر نافذة التأكيد → اضغط **تثبيت**
5. سيظهر أيقونة على سطح المكتب
6. عند فتحها، تعمل كنافذة مستقلة بدون شريط المتصفح

### على Chrome (ماك):
1. افتح النظام
2. من القائمة (⋮) → **تثبيت التطبيق**
3. سيظهر في Launchpad

### على الهاتف (Android):
1. افتح Chrome على `http://IP:3000`
2. من القائمة (⋮) → **تثبيت التطبيق**
3. سيظهر أيقونة على الشاشة الرئيسية

### على iPhone:
1. افتح Safari على `http://IP:3000`
2. اضغط زر المشاركة (□↑)
3. اختر **على شاشة الرئيسية**
4. اضغط **إضافة**

## الطريقة 2: اختصار على سطح المكتب (الأسرع)

### على ويندوز:

#### الطريقة أ: سكريبت تلقائي
1. دبل كلك على: `scripts/install-desktop-shortcut-windows.bat`
2. سيظهر اختصار "مطعم التكية" على سطح المكتب
3. دبل كلك عليه → يبدأ النظام ويفتح المتصفح تلقائياً

#### الطريقة ب: يدوياً
1. كليك يمين على `scripts/desktop-shortcut-windows.bat`
2. اختر **إرسال إلى** → **سطح المكتب (إنشاء اختصار)**
3. غيّر اسم الاختصار إلى "مطعم التكية"
4. (اختياري) غيّر الأيقونة: كليك يمين → خصائص → تغيير الأيقونة → اختر `public/icon-192.png`

### على لينكس:

```bash
# شغّل سكريبت التثبيت
cd /path/to/restaurant
bash scripts/install-desktop-shortcut-linux.sh
```

سيظهر اختصار على سطح المكتب. دبل كلك عليه → يبدأ النظام.

---

## الطريقة 3: تشغيل تلقائي عند بدء الكمبيوتر

### على ويندوز:
1. اضغط `Win + R` واكتب `shell:startup`
2. انسخ اختصار "مطعم التكية" إلى هذا المجلد
3. عند بدء تشغيل الكمبيوتر، سيبدأ النظام تلقائياً

### على لينكس:
```bash
crontab -e
# أضف السطر التالي:
@reboot sleep 30 && cd /path/to/restaurant && bash scripts/desktop-shortcut-linux.sh
```

## أوامر سريعة

| الأمر | الوصف |
|---|---|
| `bun run start:all` | تشغيل النظام |
| `bun run stop` | إيقاف النظام |
| `bun run install:shortcut` | إنشاء اختصار على سطح المكتب |
| `bun run backup` | نسخة احتياطية |

## ما الذي ستحصل عليه بعد التثبيت؟

### بعد تثبيت PWA:
- ✅ أيقونة على سطح المكتب
- ✅ نافذة مستقلة بدون شريط المتصفح
- ✅ يعمل بشكل أسرع
- ✅ اختصارات سريعة (كليك يمين على الأيقونة):
  - طلبات الزبائن
  - فاتورة جديدة
  - المنيو العام
  - طباعة QR Code

### بعد إنشاء اختصار:
- ✅ تشغيل بنقرة واحدة
- ✅ يبدأ النظام تلقائياً
- ✅ يفتح المتصفح تلقائياً
- ✅ لا حاجة لفتح المتصفح يدوياً

---

## نصائح مهمة

1. **أغلق النوافذ الأخرى** قبل فتح التطبيق لتفادي التعارض
2. **استخدم وضع ملء الشاشة** (F11) للحصول على أفضل تجربة
3. **ضع الاختصار على شريط المهام** (ويندوز) للوصول السريع
4. **فعّل التشغيل التلقائي** لبدء العمل فور تشغيل الكمبيوتر

---

## حل المشاكل

### المشكلة: لا تظهر أيقونة التثبيت في المتصفح
- تأكد أنك تستخدم Chrome أو Edge
- افتح `http://localhost:3000` (وليس عنوان IP)
- امسح الكاش وأعد المحاولة

### المشكلة: الاختصار لا يعمل
- تأكد أن المسار صحيح
- شغّل `bun run start:all` يدوياً للتأكد من عمل النظام
- تأكد أن Bun مثبت في PATH

### المشكلة: النظام بطيء
- أغلق التبويبات الأخرى في المتصفح
- استخدم PWA بدلاً من المتصفح العادي
- تأكد أن الكمبيوتر لديه 4GB+ رام
